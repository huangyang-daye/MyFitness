## 指标说明

- **Hit@K（命中率/准确率）**：Top-K 中至少召回 1 个相关块
- **Recall@K**：`|TopK ∩ 相关集| / |相关集|`
- **Precision@K**：`|TopK ∩ 相关集| / |TopK|`
- **Top-1 准确率**：排名第一的块属于相关集
- **MRR**：首个相关块排名的倒数均值
